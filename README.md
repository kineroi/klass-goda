# Класс года — рейтинг классов

Сайт рейтинга классов КГУ «Николаевская основная средняя школа».
Баллы начисляются каждую четверть, по итогам года в каждой лиге выбирается «Класс года».

- **Младшая лига:** 2-3, 4 классы
- **Старшая лига:** 5-6, 7-8, 9 классы

## Как внести баллы

Все баллы хранятся в одном файле — [`data/scores.csv`](data/scores.csv). Одна строка = одно начисление.

1. Откройте файл `data/scores.csv` на GitHub.
2. Нажмите на значок карандаша (**Edit this file**).
3. Добавьте строки в конец файла.
4. Нажмите **Commit changes…** → **Commit changes**.
5. Через 1–2 минуты сайт обновится сам.

### Формат строки

```
дата,четверть,класс,критерий,баллы,причина
```

| Поле | Что писать | Пример |
|---|---|---|
| дата | ГГГГ-ММ-ДД | `2026-10-12` |
| четверть | 1, 2, 3 или 4 | `1` |
| класс | `2-3`, `4`, `5-6`, `7-8`, `9` | `7-8` |
| критерий | код из таблицы ниже (или название по-русски) | `events` |
| баллы | число; для замечаний — с минусом | `3` или `-1` |
| причина | коротко, за что | `Осенний кросс — 1 место` |

Если в причине есть запятая — возьмите её в кавычки: `"Субботник, уборка двора"`.

### Критерии

| Код | Критерий | Макс. за четверть | Как вносить |
|---|---|---|---|
| `study` | Учёба | 25 | Одна строка в конце четверти: 25 × доля учеников на «4» и «5» (округлить) |
| `attendance` | Посещаемость | 15 | Одна строка в конце четверти: 15 / 12 / 9 / 5 / 0 |
| `discipline` | Дисциплина | 10 | У всех уже есть 10 баллов. Вносите только замечания: `-1` за каждое |
| `order` | Порядок и дежурство | 5 | По итогам проверок, от 0 до 5 |
| `events` | Школьные мероприятия | 20 | `2` за участие половины класса; призовые: `3` / `2` / `1` отдельной строкой |
| `olympiads` | Олимпиады и конкурсы | 15 | За каждого ученика: участие в районном 1, призёр района 3, области 5, республики 8. Для 2–4 классов — также школьные и онлайн-конкурсы |
| `good` | Добрые дела и инициативы | 10 | От 2 до 5 за дело, по решению совета |

Сайт сам суммирует баллы и **не даёт превысить максимум** по критерию — лишние баллы просто не засчитываются (а в журнале всё равно видны).

### Примеры

```
2026-10-12,1,7-8,events,2,Осенний кросс — участие
2026-10-12,1,7-8,events,3,Осенний кросс — 1 место
2026-10-14,1,5-6,discipline,-1,Опоздание на урок
2026-10-30,1,3,study,18,"7 из 10 на «4» и «5»"
```

Если строка написана с ошибкой, она не учитывается, а внизу сайта появится красная подсказка с номером строки.

## Настройки

Файл [`data/config.json`](data/config.json): название школы, учебный год, **даты четвертей**, классы и критерии.
Новый учебный год: поменяйте `year` и даты четвертей, а старый `scores.csv` переименуйте (например, в `scores-2026-2027.csv`) и создайте новый с одной строкой заголовка.

## Демо

Чтобы посмотреть, как выглядит заполненный рейтинг, откройте сайт с `?demo=1` в конце адреса.
